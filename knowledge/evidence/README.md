# Knowledge Evidence

## Purpose

The `evidence/` directory contains validated observations derived from authoritative source material.

Evidence is distinct from raw source documents. It represents reviewed findings that preserve complete provenance back to the original documents stored under `knowledge/sources/`.

---

# Principles

Evidence maintained within this directory shall:

- Be traceable to one or more original source documents.
- Preserve complete provenance.
- Be deterministic and reviewable.
- Remain evidence-driven rather than assumption-driven.
- Never modify or replace the original source material.

---

# Relationship to Other Repository Areas

```
Sources
    ↓
Evidence
    ↓
Knowledge Base (future)
    ↓
Capability Consumption (future)
```

The `evidence/` directory contains validated observations only. It does not contain source documents or production capability implementations.
