# Knowledge Glossary

## Purpose

The `glossary/` directory contains approved terminology used throughout the Knowledge Engineering (KE) workstream.

The glossary establishes a controlled vocabulary to ensure that engineering concepts, repository metadata, and governance terminology are used consistently across the Jarvis repository.

---

# Principles

Glossary entries shall:

- Be evidence-driven.
- Be reviewed before approval.
- Remain version controlled.
- Use deterministic definitions.
- Reference authoritative sources where appropriate.

---

# Relationship to Knowledge Engineering

The glossary supports consistent interpretation of:

- Knowledge assets
- Repository governance
- Engineering standards
- Metadata
- Future ontology development
- Future capability consumption

The glossary does not replace original source material and does not introduce new engineering authority.

---

# Scope

KE-0001 establishes this directory as the future home for approved engineering terminology.

No glossary entries are created as part of this task.
