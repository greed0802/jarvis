# Council Sources

## Purpose

The `councils/` directory contains original, authoritative council specifications and engineering documentation acquired from Australian local government authorities.

This directory stores immutable source material only. Documents remain unchanged from their acquired form and are organized by jurisdiction.

---

# Structure

```
councils/
├── nsw/
├── victoria/
├── queensland/
├── western_australia/
├── south_australia/
├── tasmania/
├── act/
└── northern_territory/
```

## Governance

Council source documents shall:

- Remain immutable after acquisition.
- Preserve their original filenames.
- Be organized by jurisdiction rather than renamed.
- Be traceable through the Knowledge Register.
- Maintain complete provenance throughout the Knowledge Engineering lifecycle.

---

# Scope

KE-0001 establishes the repository structure only.

No council specifications are populated as part of this task.
