# Standards Sources

## Purpose

The `standards/` directory contains original, authoritative standards documents managed by the Knowledge Engineering (KE) workstream.

This directory stores immutable source material only. Documents remain unchanged from their acquired form and are organized into standards-specific collections.

---

# Structure

```
standards/
├── anzsmm/
├── australian_standards/
└── ncc/
```

## Categories

### ANZSMM

Contains original Australian and New Zealand Standard Method of Measurement documents.

### Australian Standards

Contains published Australian Standards acquired for engineering reference.

### NCC

Contains National Construction Code source material.

---

# Governance

All documents within this directory shall:

- Remain immutable.
- Preserve original filenames.
- Be organized by repository structure rather than renaming.
- Be traceable through the Knowledge Register.
- Support deterministic knowledge acquisition and future evidence generation.

---

# Scope

KE-0001 establishes the repository structure only.

No standards are populated as part of this task.
