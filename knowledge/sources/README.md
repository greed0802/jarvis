# Knowledge Sources

## Purpose

The `sources/` directory contains the original, authoritative engineering documents managed by the Knowledge Engineering (KE) workstream.

This directory is the repository's immutable source collection. It exists to preserve provenance while separating raw inputs from validated knowledge and future capability consumption.

---

# Principles

Source material shall adhere to the following rules:

- Original documents remain immutable.
- Original filenames are preserved.
- Repository organization is provided by folders rather than renaming files.
- Metadata is maintained separately from source documents.
- Every source remains traceable throughout the Knowledge Engineering lifecycle.

# Scope

This directory stores collected source material only.

It does **not** contain:

- Evidence
- Extracted knowledge
- Ontologies
- AI-generated content
- Production capability artifacts

Those outputs belong in their respective Knowledge Engineering areas.
