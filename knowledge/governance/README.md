# Knowledge Engineering Governance

## Purpose

This directory contains the governance documentation for the Knowledge Engineering (KE) workstream.

Knowledge Engineering establishes the deterministic acquisition, organization, review, and stewardship of engineering knowledge within the Jarvis repository. These governance documents define policy only and introduce no production functionality.

---

# Governance Documents

| Document | Purpose |
|----------|---------|
| `KE_PRINCIPLES.md` | Core principles governing Knowledge Engineering |
| `INVENTORY_POLICY.md` | Rules for acquiring and organizing source material |
| `KNOWLEDGE_LIFECYCLE.md` | Lifecycle from acquisition through capability consumption |

---

# Governance Objectives

The Knowledge Engineering workstream ensures that:

- Original source documents remain immutable.
- Original filenames are preserved.
- Repository organization is deterministic.
- Knowledge remains evidence-driven and reviewable.
- Complete provenance is maintained.
- Capability Engineering remains independent from Knowledge Engineering.

---

# Scope

The governance documents within this directory establish repository policy only.

They do **not** introduce:

- OCR
- AI extraction
- Parsing
- Ontology generation
- Search infrastructure
- Production capability implementation

Those activities are addressed by future Knowledge Engineering work packages.
