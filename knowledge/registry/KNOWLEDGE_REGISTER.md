# Knowledge Register

## Purpose

The Knowledge Register provides the authoritative inventory of knowledge assets managed by the Knowledge Engineering (KE) workstream.

KE-0001 establishes the register structure only. No knowledge assets are populated as part of this task.

---

# Register Fields

Each knowledge asset shall record, at minimum, the following metadata.

| Field | Description |
|--------|-------------|
| ID | Unique Knowledge Identifier (e.g. KN-000001) |
| Title | Human-readable title of the asset |
| Category | Knowledge category (ANZSMM, Australian Standards, NCC, Council Specifications, Engineering Specifications, Engineering Reports, Historical Projects, Glossary, Future Knowledge) |
| Source | Origin of the document or information |
| Status | Current processing status |
| State | Governance state (Draft, Under Review, Approved, Archived) |
| Authority | Publishing or governing authority |
| Version | Source document version or revision |
| OCR Required | Yes / No |
| Notes | Additional governance or review notes |

# Governance

The Knowledge Register is metadata only.

It does not modify, rename, or replace original source documents.

Every registered knowledge asset must maintain deterministic traceability back to its original immutable source.
