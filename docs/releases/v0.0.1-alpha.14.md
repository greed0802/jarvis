## Summary

This release introduces **CP-0001**, the CheckMate CLI Application — a command-line interface that consumes the permanently frozen CheckMate application architecture. No architectural changes were introduced. The CLI is a pure consumer of the existing pipeline.

### What CP-0001 Delivers

The `checkmate` CLI provides four commands:

| Command | Description |
|---------|-------------|
| `checkmate analyze <input>` | Full pipeline: parse interpretation → render → review → export |
| `checkmate render <input>` | Render a PresentationModel to a chosen format |
| `checkmate export <input>` | Export a RenderedDocument to a file format |
| `checkmate version` | Display application and architecture version info |

### CLI Application Architecture

| Stage | Consumed Component | Authority |
|-------|-------------------|-----------|
| Input | `BOQIntelligenceResult` + `ValidationFindings` | EQ-0021 |
| Application | `run()` (ApplicationContext, Interpretation) | IP-0002/IP-0003 |
| Presentation | `assemble()` → `PresentationModel` | IP-0005 |
| Review | `create_review_session()` → `ReviewSession` | IP-0006 |
| Rendering | 4 renderers (markdown, html, json, terminal) | IP-0007 |
| Export | 4 exporters (md, html, json, txt) | IP-0008 |
