## Summary

This release permanently freezes IP-0001, delivering 8 semantic intelligence capabilities to BOQ Intelligence. It also introduces the Implementation Governance framework, a new permanent governance document that governs all future implementation work.

## New Features

### BOQ Intelligence Increment 4 — Semantic Intelligence

8 deterministic semantic capabilities implemented as pure functions over `list[BOQRow]`:

| Capability | Description |
|-----------|-------------|
| Vocabulary Extraction | Top-50 engineering term frequency from Item descriptions |
| Head1 Text Categorization | Admin vs Trade-Specific classification using frozen patterns |
| Administrative Pattern Detection | Boilerplate pattern detection per section (requires hierarchy) |
| Section Code Enumeration | 61 sections (A–Bi) enumerated with codes and names |
| UOM Distribution Reporting | Frequency counts and percentages across 7 UOM types |
| Header Level Count Distribution | Head1–Head4 distribution (1,951 total across 4 levels) |
| "Items Always Quantify" Enforcement | Invariant check — no violations detected in production fixture |
| Administrative Sub-Template Recognition | 5-step template sequence detection by section |

**API:** `analyze_boq(rows, include_semantic=True)`

**Backward compatibility:** `include_semantic` defaults to `False`, all Increment 1-3 behavior preserved.
