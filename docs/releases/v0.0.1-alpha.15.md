### Storage Architecture

**Decision:** Hybrid Storage Model
- **Git:** Metadata, governance, evidence (text-based assets)
- **External:** Raw knowledge sources (PDF, XLSX, DWG, CBX, etc.)
- **Rationale:** Scalability for 24GB+ corpus with long-term growth
