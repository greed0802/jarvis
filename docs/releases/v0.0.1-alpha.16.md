## Governance Changes

### Workstream Governance

A unified [Workstream Governance Charter](../../docs/governance/WORKSTREAM_GOVERNANCE.md) now governs all repository workstreams:

| Workstream | Prefix | Register |
|------------|--------|----------|
| Engineering Questions | EQ- | `docs/engineering/Engineering_Register.md` |
| Architecture Decision Records | ADR- | `docs/decisions/ADR_Index.md` |
| Knowledge Engineering | KE- | `docs/knowledge/Knowledge_Register.md` |
| Capability Projects | CP- | `docs/planning/Capability_Register.md` |
| Capability Builds | CB- | `docs/planning/Capability_Roadmap.md` |
| Milestones | MS- | Release/roadmap documents |
| Releases | v | `docs/releases/` |

### Identifier Collision Resolution

During the Governance Harmonization Sprint, historical identifier collisions were detected and resolved:

- EQ-0017 (Historical: Trade Classification Authority) → EQ-0022 (renumbered)
- EQ-0019 (Historical: Execution Runtime) → EQ-0023 (renumbered)
- EQ-0019 preserved as PERMANENTLY FROZEN for BOQ Semantic Intelligence Increment 1
- KE-0002 relocated from `docs/engineering/questions/` to `docs/knowledge/questions/`

### Knowledge Engineering Separation

Knowledge Engineering is now governed independently from Engineering Questions:
- Knowledge Register lives in `docs/knowledge/`
- KE identifiers are distinct from EQ identifiers
- Knowledge evidence packages live in `docs/execution/KE-XXXX-R/`
